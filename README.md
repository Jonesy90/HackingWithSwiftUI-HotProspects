# Hacking With SwiftUI - Hot Prospects

## Description:
Hot Prospects is an app to track who you meet at conferences or events. The idea is it will show your QR code, store the attendees information and others can scan the code to add you to their list of possible leads.

## What I Learned:
- Introduction to TabView.
- Introduction and understanding when and how to use the Results type.
- Image Interpolation: This is used to prevent streched out images having their pixels blended. Allowing image interpolation may have caused issues when dealing with precise pixels.
- Introduction to Context Menus.
- Introduction to Swipe Actions.
- Introduction to scheduling local notifications.
- Introduction to Swit package dependencies.
